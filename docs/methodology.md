# 分析方法与解释边界

## 为什么不是一条“粉丝成长曲线”

同一次采集得到的是作品在采集时的累计播放量。2022 年的作品已经累积数年，2025 年的作品较新；不能把它们画出的曲线解释为创作者当年获得的流量。TraceLab 的横轴是作品发布日期，纵轴明确标注累计值，所有报告重复说明这一限制。

目前没有连续快照，不输出历史粉丝增长、发布当日流量、因果归因或强制生涯分期。

## 指标

| 指标 | 定义 / 缺失处理 |
| --- | --- |
| 作品数量 | 校验后唯一视频 ID 数量；不假定样本覆盖全历史 |
| 近期播放中位数 | 按发布时间排序的最后 12 条作品中，对非空播放量求中位数；同时显示有效样本数，不用更早作品补足 |
| 总体播放中位数 | 所有非空、有限播放计数的中位数；0 是有效值 |
| 发布频率 | `(作品数 - 1) / (首末作品天数跨度 / 30.4375)`；样本跨度不足 30 天显示暂无数据 |
| 互动率 | `(点赞 + 投币 + 收藏 + 评论 + 分享) / 播放量`；任一分子缺失或播放量为 0 时为 null |
| 主题占比 | 该主题作品数量 / 全部作品数量；既无分区或标签、又未匹配关键词的归为“其他内容” |
| 趋势线 | 当前筛选范围内，按日期顺序最近 7 条有效作品的指标中位数，不是流量时间序列 |

互动率是动作数之比，不是独立互动用户率，理论上可以超过 100%。评论数是计数，不等于已经取得评论正文。

## 相对表现

`Relative Performance = 当前视频累计播放量 / 可比作品累计播放量中位数`

可比组排除自身，并同时满足：

1. 发布日期相距不超过 120 天。
2. 采集日期相距不超过 7 天。
3. 两条作品都发布至少 30 天；对照与当前作品的发布时长之比在 0.67–1.5 之间。
4. 内容形式相同（video / short / live）。unknown 不参与比较。
5. 视频长度之比在 0.5–2 之间；长度缺失、为 0 或播放缺失不参与。
6. 至少 5 条可比作品，中位数大于 0。

条件不足时保留明确原因、已有对照 ID 和可计算的基准值，相对表现为 null。不会自动放宽阈值“凑出爆款”。≥2 倍为高表现候选，按相对表现排序最多展示 6 条。

时长和时间匹配只能缓解可比性问题，不能完全控制内容题材、分发、推广或累积速度差异；相对表现不是公平排行榜。详见作品详情里的逐项比较条件与对照来源。

## 主题与变化候选

主题来源保留为 `provided`（数据提供者）、`platform`（B 站分区）、`rule`（标题/简介/标签关键词）或 `llm`。Demo 使用预置标签；CSV 缺少 topic 时规则分类；网站公开接口优先使用 B 站分区，取不到时规则分类并给出警告。

分区是投稿时选择的，反映平台归类，不等于内容主题：同一分区内的细分方向无法区分，需要时可使用 LLM 分类。关键词规则只覆盖 4 个主题，范围外的作品会归为“其他内容”。

相邻**日历季度**均有至少 5 条作品，某一主题占比增加至少 40 个百分点时，标记主题组合变化。缺失季度不跨越比较。这个阈值是可解释的 MVP 启发式，没有统计显著性或变化点模型的含义。名称使用“候选”或“占比变化”，不使用“确定转折”。

季度堆叠图展示主题作品比例。跨主题播放比较展示各自中位数，明确没有控制发布年龄和样本规模。每个主题可回溯到成员作品与代表样本。

## 观众反馈

Demo 的 12 条评论完全合成，覆盖播放量最高的 3 条模拟作品。Import 按用户提供的 comments 字段分析。Live 的评论为可选能力，失败产生警告但不阻断分析。

规则模式按关键词归组，同一条评论可以归属多个讨论主题。AI 模式提供主题、情绪标签和原始 commentIds。默认展示当前组前 3 条评论，不声称随机抽样或总体情绪比例；完整样本可在 JSON 和对应作品详情查看。没有获取弹幕、字幕或视频画面。

## AI 与统计隔离

LLM 不负责计算数字。第一次请求只分类内容与聚类评论，代码校验 ID 与主题数量后重新计算所有指标。第二次请求拿到**重新计算后的**统计，输出创作者概览、创作轨迹、关键转折、内容特点和分析结论五个章节。

每个章节必须含原始视频 ID，并区分 `fact / association / hypothesis`。服务端验证 JSON Schema、长度、章节完整性、分类覆盖、引用存在性；模型拒绝、截断、超时、限流、结构错误或伪造引用都会拒绝结果，保留基础报告。

模型最多读取最近 120 条作品、前 80 条评论；其他作品保留原分类。结构与引用校验不能证明语义或因果判断正确，因此界面注明需人工复核。API 未配置时不假装成功、不把规则报告称为 AI 生成。
